# Triage Labels

The triage skills name five roles. Map each role to its label string in this table.

| Role (skill name) | Label in our tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill names a role, apply the label from the "Label in our tracker" column. Do not invent a label.

Leave this table unchanged unless the maintainer asks you to change the label vocabulary.
